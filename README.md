# OSINT PRO MAX+

Painel estático para organizar pesquisas em fontes públicas. O site gera links para serviços externos; não faz scraping nem retorna resultados verificados no próprio painel.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em Build and deployment, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
5. Salve e aguarde o link publicado aparecer na seção Pages.

## Recursos
- Layout responsivo para computador e celular
- Pesquisas por web, GitHub, plataformas públicas, documentos e notícias
- Tipos de consulta: geral, username, domínio, desenvolvimento, documentos e notícias
- Histórico temporário na sessão, copiar URLs e exportar JSON
- Sem dependências, servidor ou banco de dados
- Links externos abrem em nova aba com `noopener noreferrer`

## Limites e uso responsável
Os links apenas encaminham a pesquisa para os serviços de origem. A ferramenta não confirma identidade, não acessa contas privadas e não contorna login, CAPTCHA ou controles de acesso. Verifique as fontes e respeite leis e termos dos serviços.
